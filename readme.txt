🛒 Android E-Commerce App – FakeStore API
Aplikasi e-commerce Android yang dibangun sebagai bagian dari Technical Assessment – FE Android. Aplikasi ini memungkinkan pengguna untuk login, melihat daftar produk, memfilter berdasarkan kategori, melihat detail produk, menambahkan ke keranjang, melihat profil, dan melakukan checkout.

🏠 Halaman Utama
Menampilkan daftar produk dari FakeStore API.

Menampilkan daftar kategori produk.

Filter produk berdasarkan kategori.


📦 Detail Produk
Menampilkan detail lengkap dari produk yang diklik.

Dapat menambahkan produk ke keranjang dari halaman detail.

🛒 Keranjang
Menampilkan daftar produk yang ditambahkan ke keranjang.

User dapat mengubah jumlah produk atau menghapus produk.

Terdapat tombol Checkout yang mengarahkan ke halaman ringkasan pesanan.

👤 Halaman Profil
Halaman profil ditampilkan dalam bentuk Bottom Sheet Dialog.


⚙️ Tech Stack
Bahasa: Kotlin

Architecture: MVVM (Model-View-ViewModel)

Networking: Retrofit

Local Storage: SQLite

Dependency Injection: Hilt


Design: Clean & Responsive UI/UX 

📡 API Endpoint
Menggunakan endpoint dari FakeStoreAPI:

Login: https://fakestoreapi.com/auth/login

Products: https://fakestoreapi.com/products

Categories: https://fakestoreapi.com/products/categories

Products by Category: https://fakestoreapi.com/products/category/{category}
